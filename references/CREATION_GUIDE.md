# 番茄平台创作指南（AI 代写歌词/风格时的依据）

> 当用户在「歌词和风格谁写」这一步选择**「你帮我写」**或**「混合」**时，
> 按本文件来创作。选「我自己写」时不要擅改用户的词。

## ★★ 动笔前先做这一步（**强制，不许跳过**）：拆解番茄爆款「怎么写」的

> **研究热歌 ≠ 研究数字。** 在听人数只用来**挑出「研究哪几首」**；
> 真正要研究的是**这些歌是怎么写出来的** —— 结构、副歌、记忆点、韵脚、意象、句子长度。
> 用户明确说过：*「不是要你收集数据研究，是要研究歌曲的创作思维模式和创作风格，数据没什么好研究的。」*

### 第 1 步：采番茄自己的榜单 —— **只为了选出样本**

```bat
cd <工作目录>
<python> <skill>/scripts/fanqie_rank.py --rank 热歌榜      :: ★ 首选：APP 官方榜
<python> <skill>/scripts/fanqie_rank.py --list-ranks       :: 看有哪些榜
```

直连**番茄音乐 APP 自己的接口**（`aid=8661` / `FmMusic`，只读、免签名、免登录、免抓包），
拿到的是**用户在 APP「排行榜」里看到的同一份数据**：

- **10 个官方榜**：热歌榜 / 抖音榜 / 飙升榜 / 经典榜 / 70后热歌 / 80后热歌 / 90后热歌 / 00后热歌 / 车载热歌 / 运动热歌
- 每榜 **50 首**，带**平台自己的名次** + **涨跌幅**（▲N/▼N/—/新上榜）
  + 真实播放量 + 收藏数 + **官方曲风标签** + 时长
- 榜单里每首的 `book_id` **可直接喂给第 2 步** → 榜单到拆解全链路闭环

产物（**用于「挑哪几首来拆」，不是研究目标本身**）：

- `<工作目录>/charts/番茄榜单-<榜名>-YYYY-MM-DD.md`
- `<工作目录>/charts/番茄榜单-<榜名>-YYYY-MM-DD.json`（供下轮对比涨跌）

> ⚠️ **网页版 ≠ APP，差距很大**：番茄音乐**网页版没有榜单页**
> （18 个候选路径 `/rank` `/chart` `/hot` `/toplist` `/music/rank` `/billboard` `/ranking` …
> **全部回落首页**，SPA catch-all；页面含「榜/排行/热歌」的可点元素 0 个；无列表 JSON 接口），
> 只有首页「热门歌曲」推荐位。
> **`fanqie_chart.py`（网页版）已降级为兜底**，只在 APP 接口不可用时才用；**不要拿它当榜单交付**。
> **「APP 榜需手机抓包（Appium / mitmproxy）」这个旧判断已作废** —— 直连接口即可。
> 但**这不影响创作研究** —— 因为我们要的是**歌词与写法**，详情页就能拿（见第 2 步）。

### 第 2 步（★ 核心）：把**热歌榜前十首**的歌词拉下来**拆解**

```bat
<python> <skill>/scripts/fanqie_lyric.py --top 10 --rank 热歌榜
```

会逐个打开歌曲详情页 `novelfm.com/music/<作品ID>`，**取平台在播版本的完整歌词**
（不是第三方歌词站 —— 那些版本常与在播版本不一致），然后自动拆成五层：

| 层 | 看什么 | 它决定了什么 |
|---|---|---|
| **结构** | 行数、有没有「整块重复副歌」、副歌块几行、整块重复几次 | 歌能不能被记住 |
| **记忆点** | hook 是哪一句、重复几次 | **副歌第一句怎么写** |
| **句式** | 平均行长 / 最短 / 最长 | 唱起来顺不顺、中老年跟不跟得上 |
| **韵脚** | 高频行尾字（只统计汉字，避开外语歌干扰） | 是否「一韵到底」 |
| **意象 / 情绪词** | 反复出现的实体词与情绪词 | 取材与共鸣点从哪来 |

产物：`<工作目录>/study/番茄歌词拆解-YYYY-MM-DD.md`（+ `.json`，含每首歌词全文）

> **为什么必须拆歌词而不是只看榜单**：榜单只告诉你「哪首火」，
> **拆解才告诉你「它凭什么火」** —— 而这个「凭什么」才是能复制到我们自己歌里的东西。
> ⚠️ 详情页**不含**作词/作曲署名 —— 所以拆解只覆盖「怎么写」，「谁写的」拿不到；
> **「什么曲风」不用猜** —— 直接用第 1 步 APP 榜单自带的**官方 `tags` 字段**（最准）。

### 第 3 步（★★ 落地）：把「榜单 + 拆解」压成**创作配方卡**

```bat
<python> <skill>/scripts/fanqie_recipe.py --ranks 热歌榜,80后热歌,90后热歌
```

**为什么还要这一步**：拆解出来的是**指标**（30~36 行、副歌 11 行的块、重复 2 次、
行尾字是「我/中/情」）—— **指标不能直接下笔**。配方卡把指标压成**参数**：
写几行、副歌留几行、整块重复几次、歌名几个字、配什么版本后缀、韵脚挑哪几个。

配方卡包含（`<工作目录>/study/番茄创作配方-YYYY-MM-DD.md`）：

| 节 | 内容 |
|---|---|
| 一 | **本期受众画像** —— 谁在听（80后/70后…）+ 主场景（KTV / 广场舞 / 车载） |
| 二 | **题材主盘** —— 官方曲风标签里哪几类是真大盘；主盘外的次盘 = 差异化机会 |
| 三 | **歌名配方** —— 字数区间 + **版本后缀占比**（多版本铺量是跑通打法）+ 起首/收尾字 |
| 四 | **结构配方** —— 总行数、单行字数、副歌块大小、整块重复次数、hook 重复次数 |
| 五 | **韵脚候选池** —— 直接可挑 |
| 六 | **情绪词 / 意象词库** —— 哪一类痛 + 用什么具象东西承载 |
| 七 | **★ 听众情绪需求四问** —— 留空模板，**必须逐条答完才许开写** |
| 八 | **★ 一句话配方** —— 可直接抄进写作 prompt 的浓缩参数 |
| 九 | **撞名校验清单** —— 本期榜单全部歌名，写歌名前逐条比对 |
| 十 | **写完自检清单** —— 拿配方反向验收成稿 |

> ⚠️ **配方卡的两条口径纪律**（脚本已内置，但你引用数字时要记住）：
> ① **受众画像只用大盘热歌榜算** —— 年龄榜（80后/90后热歌）本来就按年龄筛过，
>   混进来统计「哪个年龄档最多」是**自我实现**，不是洞察。
> ② **同一首歌会在多个榜里出现**，脚本会按作品 ID 去重 ——
>   不去重的话曲风标签被灌水、歌名统计被放大、还会把「同榜出现」误报成「撞名」。

### 第 4~6 步（拿到配方卡之后）

4. **回答配方卡第七节的「听众情绪需求四问」→ 写进 `HOT_SONG_RESEARCH.md` 该轮的 D 节。**
   四问不答完，不许开写（详见下一节）。
5. 读 `HOT_SONG_RESEARCH.md` 的**最后一期研究**，拿历史积累（**撞名黑名单**也在这里）；
   顺手交叉**第三方榜**看全网大盘风向（抖音热歌榜 / 酷狗 / 短视频热歌榜）——
   但**冲突时一律以番茄 APP 官方榜为准**（那才是我们真正的听众）。
6. 把本轮结论**追加写回** `HOT_SONG_RESEARCH.md`，**然后才动笔**。

### ★ 研究成果必须落到「听众情绪需求」这一层，而不只是罗列歌名

**这是用户反复强调的核心要求**：*「能挖掘洞察听众用户的情绪需求，产生情感共鸣。」*

每轮研究都要显式回答这四个问题（写进 `HOT_SONG_RESEARCH.md` 该轮的 D 节）：

| 问题 | 为什么要写 |
|---|---|
| **这期最热的那几首，听众在它们身上要的是什么情绪？** | 罗列歌名没用，要说出「他们在找什么」 |
| **这个情绪是「宣泄」还是「出口」？** | 番茄调性偏温暖正向，纯沉溺不如给出口（第八轮已修正过一次判断） |
| **听众的现实处境是什么？如何共鸣？** | 例：在外打工/空巢/带孙/退休——要落到具体处境，歌才有画面 |
| **我要写的那首，歌名/副歌第一句怎么让 TA 觉得「这说的就是我」？** | 这一条直接决定点击率 |

理由：爆款是有规律可循的，研究 20 分钟能显著提升命中率。
历史上研究已**多次推翻本文档原判断**——国风优先级（原以为低）、对伤感的态度（原以为要避免）、
以及「国风是第一大题材」（网页版口径，换 APP 官方标签后已修正）。
另外**只查第三方榜会跑偏**：第十轮我全程用搜狐/酷狗/歌曲吧的榜，
而番茄 APP 官方榜显示《琵琶曲》在 **00后热歌榜 #1**、
《如果累了就回故乡（少年版）》在**热歌榜 #5** 且同时进 80/90后榜 ——
这就是「锚打错地方」的代价。

> **欢迎主动提改进**：用户明确说过 *「你也可以提供更好的创意和想法去改进歌曲创作，
> 最好能持续输出有爆款潜质的音乐」*。
> 发现能提高命中率的新规律，**直接写进配方卡与本文件，并大胆用在下一首里**，
> 但必须留痕（改了什么、依据是第几轮哪一首）。自检口径：
> **「这个改动是数据看出来的，还是我想当然的？」** —— 后者不许写进配方。

## 一、先搞清楚歌写给谁听

番茄音频创作平台上传的歌，主要分发到**番茄音乐 / 番茄畅听 / 抖音等字节系**渠道。
番茄音乐的听众结构和汽水音乐完全不同，这一点决定了创作方向：

| 维度 | 番茄音乐（我们的主战场） | 汽水音乐（对照组） |
|---|---|---|
| 核心用户 | **60 后、70 后占比超 40%** | 90 后、00 后为主 |
| 地域 | 三四线及以下，下沉市场 | 一二线 |
| 首页标签 | 热门短剧、DJ 热榜、**广场舞神曲**、K 歌金曲 | 新锐、小众、国际化 |
| 推荐内容 | 经典老歌、抖音热歌、方言歌、地方戏曲 | AI 孵化、独立音乐 |
| 传播方式 | 熟人社交（微信家庭群、语音评论、一键点赞） | 弱化社交，沉浸式听歌 |
| 商业模式 | 纯免费 + 看广告赚金币 | 免费获客 + 会员变现 |

**一句话结论**：写给**三四线城市的中老年**听，他们要的是**听得懂、有共鸣、能跟着哼**。

> ⚠️ 以上基于公开报道（QuestMobile 等）整理，属于推断而非平台官方数据。
> 若用户有自己的后台播放数据，**以用户数据为准**——问问他"你哪首歌播放最高"，比猜更准。

## 二、题材优先级（从高到低）

> 以下优先级已根据 2026-08-30 期热歌研究修订，详见 `HOT_SONG_RESEARCH.md`。

| 优先级 | 题材 | 为什么 | 示例角度 |
|---|---|---|---|
| ★★★ | **国风 / 古风** | **研究新发现：占比最高的品类之一**（番茄 App 内 7 首占 3 首，抖音榜多期有 2~3 首）。破圈公式：民乐乐器（唢呐/古琴/二胡）开头抓耳 + 现代节拍 + 古典意象 | 江南、红尘、归舟、山海、旧时月色 |
| ★★★ | **亲情 / 乡愁 / 怀旧** | 中老年最稳定的情感入口 | 父母的白发、老屋、村口、儿时饭香、离乡打工 |
| ★★★ | **都市 / 打工人 / 归途** | **研究新发现的高频题材**，共鸣极强 | 城市晚风、加班后的地铁、过年回家、他乡与故乡 |
| ★★☆ | **人生感悟 / 励志** | 正能量、适合转发 | 半生已过、生活不易仍向前、平凡人的光 |
| ★★☆ | **广场舞 / DJ 节奏** | 平台核心标签，传播快 | 强节拍、易跟跳、歌词简单重复 |
| ★★☆ | **爱情 / 伤感（成熟向）** | **修正**：伤感情歌是情感类短视频标配 BGM，不必回避；但要**有出口**（释怀/祝福/成长），不能纯沉溺 | 老伴、多年后重逢、错过的人、笑着放手 |
| ★★☆ | **对唱形式** | **研究新发现**：番茄 App 内多首对唱，熟人社交传播更有优势 | 男女对唱、相伴到老、两地相思 |
| ★☆☆ | **地域 / 方言特色** | 本地化内容有推荐优势 | 方言词、地方意象 |
| ★☆☆ | **老歌新唱 / 改编** | 经典旋律自带认知度，新编曲反差感强（如民歌 + 电子） | 老歌重新编曲、方言版、DJ版 |
| ✘ | 小众实验、纯英文、抽象诗意、快嘴说唱 | 与听众画像不匹配 | — |

## 三、歌词写法（硬要求）

1. **直白优先**：一句话能说清的情绪，不要用三个意象去绕。
2. **押韵工整**：主歌叙事、副歌抒情，韵脚统一，别中途换韵。
3. **有具体画面**：老屋、缝纫机、绿皮火车、搪瓷缸、晒谷场、孩子的书包——
   具体名词比抽象形容词有力得多。
4. **结构标准**：主歌 → 预副歌 → 副歌 → 间奏 → 副歌 → 尾句。全曲 200~350 字。
5. **副歌要能哼**：短句、重复、有记忆点，最好一句能当标题。
6. **★ 副歌「15 秒法则」**（热歌研究得出，很重要）：短视频二创几乎只截取**副歌 15~30 秒**，
   所以别写慢热结构——**前 15 秒内必须把情绪和记忆点抛出来**，
   第一句副歌就要是全曲最抓人的那一句。慢热 = 传播吃亏。
7. **写对唱时**：分工要清楚（男声叙事 / 女声抒情，或一问一答），
   合唱句放在副歌，方便熟人社交场景（夫妻、老伴）传唱。

**必须避免**：
- 英文单词夹杂（"baby""tonight"这类在这批听众里是减分项）
- 网络流行梗（过时快，且代际不通）
- 意象堆叠、看不懂在说什么
- 过度伤感、消极厌世（平台调性偏温暖/正向）
- 说唱快嘴、BPM 过高（中老年跟不上）

**示例（怀旧亲情向，副歌）**：

> 灶台上的火还亮着，你却已弯了腰<br>
> 那些年你背我走过的路，如今该我陪你慢慢绕<br>
> 岁月啊你慢些走，让我多喊一声妈<br>
> 别让那炊烟散尽，才想起回家

## 四、风格描述（填进 tasks.csv 的「风格描述」列）

风格 prompt 由**曲风 + 乐器 + BPM + 人声 + 情绪 + 意象**堆叠而成（妙响、MiniMax 备选端都吃这套写法）。
在妙响里它填进创作页「专业模式」的曲风输入框（`textarea`），在旧脚本里填 `tasks.csv` 的「风格描述」列。
以下模板可直接套用：

| 方向 | 风格描述模板 |
|---|---|
| **国风古风** ★ | `国风 古风 古筝 二胡 笛子 现代鼓点 78BPM 女声 戏腔 意境 江南 古典 悠远` |
| 怀旧亲情 | `怀旧 流行 钢琴 木吉他 弦乐 72BPM 男声 温暖 深情 亲情 故乡 叙事` |
| **都市归途** ★ | `都市 民谣 流行 电吉他 钢琴 82BPM 男声 沧桑 叙事 城市 打工人 归途 共鸣` |
| 人生感悟 | `励志 流行 钢琴 鼓 80BPM 男声 沧桑 坚定 人生 感悟 治愈` |
| 广场舞 DJ | `DJ 电子 舞曲 128BPM 女声 欢快 动感 节奏 广场舞 热闹` |
| 成熟爱情 | `伤感 流行情歌 钢琴 弦乐 68BPM 女声 深情 遗憾 释怀 怀念` |
| **男女对唱** ★ | `对唱 流行 钢琴 弦乐 74BPM 男女声 深情 对话 相伴 温暖 叙事` |
| 治愈温暖 | `治愈 民谣 木吉他 钢琴 76BPM 女声 清新 温暖 希望 阳光` |

（★ = 2026-08-30 热歌研究新增的方向）

**参数建议**：
- 抒情类 BPM **68~84**（慢，好跟唱）
- 广场舞/DJ 类 BPM **120~132**（强节奏，好跟跳）
- 人声：中老年听众对**温暖男声/成熟女声**接受度最高，避免尖细电音人声

## 六、批量创作时的注意事项

- **同批次避免同质化**：一次写 5 首，别全是失恋情歌，题材和 BPM 要错开。
- **歌名要好搜**：中老年常直接搜歌名，用直白有画面感的名字
  （如《村口的老槐树》优于《归途的隐喻》）。
- **每首都要能独立成立**：不要写"上集下集"式的连续叙事。
