# 热歌研究档案（代创作前必读，持续迭代）

> **为什么要有这个文件**：凭感觉写歌 = 碰运气。
> 代创作前先研究当期热歌榜，把爆款的「创作思维模式」提炼出来再去写，命中率完全不同。
> **每次代创作前，先看本文件最后一期的研究，再做一次新搜索补充当期数据。**

## 研究方法（★ 2026-09-21 起，照做即可）

**现行标准流程（App 内部 + Tool 自动化，已全部固化）**：

1. **★ 跑 `fanqie_rank.py` 采番茄音乐 APP 官方榜**（**最准，且已打通**）：
   ```bat
   python fanqie_rank.py --rank 热歌榜              :: 单榜
   python fanqie_rank.py --rank 飙升榜,80后热歌,90后热歌
   python fanqie_rank.py --rank all --limit 50      :: 10 个榜全采（约 497 首）
   python fanqie_rank.py --list-ranks               :: 列出全部榜名
   ```
   拿到的是**用户在 APP「排行榜」里看到的同一份数据**：官方名次 + 涨跌幅 + 真实播放量
   + 收藏数 + **官方曲风标签**。子命令、字段语义、踩坑记录见 **G 节**。
2. **★ 跑 `fanqie_lyric.py` 拆 TOP10 歌词五层**（**研究本体在这里**）：
   ```bat
   python fanqie_lyric.py --top 10
   ```
   输出 `<workdir>/study/番茄歌词拆解-YYYY-MM-DD.md`（逐首全文 + 结构/记忆点/句式/韵脚/意象）。
3. **交叉第三方榜看大盘风向**（抖音热歌榜 / 酷狗 / 短视频热歌榜）：搜索即可，
   **与第 1 步冲突时以番茄 APP 官方榜为准**。
4. **提炼而非抄歌名**：重点看**风格分布**和**爆款共性**，不是照抄某首歌。
5. **写回本文件**：新一期追加在最后，标注日期和来源，形成可对比的历史积累。

> ⚠️ **不要再用网页版数据当榜单**：番茄音乐**网页版没有榜单页**（18 个候选路径全回落首页），
> 只有首页「热门歌曲」推荐位，且**与 APP 榜单差距很大**。
> `fanqie_chart.py`（网页版）**已降级为兜底**，仅当 APP 接口不可用时才用。
>
> **历史口径提醒**：本文件 2026-08-30 ~ 2026-09-20 的期次用的是**第三方榜**
> （搜狐 / 酷狗 / 歌曲吧 / eemp3…），第十一轮 A/B 节用的是**网页版自排名次**。
> 这两类数据**口径都低于 G 节的 APP 官方榜**，**引用时不可与新榜数字混用**。

### C. 爆款共性（多篇文章口径一致，可信度高）

1. **旋律简洁抓耳**：主歌副歌区分明显，副歌记忆点强，**听一两遍就能跟着哼**。
2. **歌词共情、接地气**：写普通人的生活日常，或人人都经历过的情感，让人有代入感。
3. **副歌就是短视频 BGM**：多数二创只截取**副歌 15~30 秒**——
   所以**副歌必须在前 15 秒内就把情绪抛出来**，慢热的结构在短视频时代传播吃亏。
4. **老歌新唱是一条捷径**：经典旋律 + 新编曲（如弥渡山歌 PHONK 版）反差感强，自带认知度。
5. **国风的破圈公式**：传统民乐乐器（唢呐/古琴/二胡）开头抓耳 + 现代节拍 + 家国/古典意象歌词。

| 上一版说法 | 本期修正 |

| 避免伤感、消极 | ⚠️ **过于绝对**。伤感/戳心情歌是情感类短视频标配 BGM，保留但要「有出口」，不能纯沉溺 |

→ 共鸣抓手：**用「时间节点」而不是「抽象情绪」**

**(4) 我要写的那首，歌名与副歌第一句怎么让 TA 觉得「这说的就是我」？**
→ 歌名走**2~6 字短词**（TOP10 平均 **4.8 字**，最短 2 字），且必须是**TA 自己会说的白话**
（梦哑 / 舞女 / 赐我 / 来迟 —— 都是口语化短词，不是文艺长句）。

**五层拆解定义与本轮答案（口径已固化进脚本输出）**：

| 层 | 看什么 | 本轮样本的答案 |
|---|---|---|
| ① 结构 | 篇幅、行数、段落怎么切 | 平均 **38.3 行**，单行平均 **10.2 字** |
| ② 记忆点 | 重复最多的那句（hook）重复几次 | hook 平均重复 **4.0 次** |
| ③ 句式 | 口语 vs 文艺、有无对白/自问 | **自问自答式独白**（「你去哪」→「问你却张不出口来回答」） |
| ④ 韵脚 | 行尾字分布 | **人(15) 你(14) 着(13) 了(12) 遇(8) 意(8) 梦(6) 下(6) 上(6) 雨(6)** |
| ⑤ 意象/情绪 | 高频名词、高频动词 | 意象：**心(25) 花(15) 雨(14) 琴(14) 琵(14) 梦(13) 泪(13) 眼(10)**；情绪：**想(15) 等(8) 放下(7) 痛(7)** |

**★ 跨曲最硬的三条规律（可直接指导写词）**：

1. **10/10 首都有「整块重复副歌」** —— 副歌块平均 **7.9 行**，整块**原样重复 2.1 次**。
   即番茄爆款的副歌**不是「提炼 1~2 句副歌句」，而是「一整段原封不动再来一遍」**。
   → 写词时副歌要写成一个**能独立成段、且值得唱两遍的 6~10 行整体**，不要只押一两句。
   （极端例：《梦哑》副歌块 **10 行**、整块重复 2 次，占全曲 41 行的近一半。）
2. **hook 平均重复 4.0 次，且 hook 就落在副歌的第一/二句里**。
   样本原句：`爱一个人要学会放下`（梦哑）/ `弹一首琵琶曲 世人争相思意`（琵琶曲，两个版本共用）/
   `赐我一场相爱`（赐我）/ `你知不知道你就是我最爱的人`（最幸福的人）/ `有你别无所求了`。
   → **副歌第一句 = hook**，写的时候就要按「歌名级别的句子」去打磨，别把力道平均分给整段。
3. **韵脚几乎全是「人/你/着/了」这类最省力的口语尾字**，不是生僻雅字；且多组混押（-i / -u / -ng）。
   → **不要为押韵去挑生僻字。** 番茄听众要的是「顺口、听得清、像说话」，
   生僻字只会让 45~70 岁的听众第一次听就卡住。

**同时反证了两条第十轮（及更早）的错误假设**：

- ❌「国风要走文言/文艺长句」→ **错**。样本单行平均 **10.2 字**，最短的《梦哑》仅 **8.4 字**，
  全是**短句**；国风爆款《琵琶曲》走的是「器物 + 白话」（弹一首琵琶曲 / 世人争相思意），
  不是文言堆砌。**国风的「古」在配器和意象上，不在句法上。**
- ❌「副歌越短越好记」→ **半错**。短的是**单句**，长的是**整块** ——
  记忆靠**重复整块**（2.1 次），不是靠把句子砍短。**别为了「好记」把副歌写成两句孤零零的口号。**

**顺带一条形态发现**：TOP10 里有 **2 首外语 vocal**（《祈神怜》梵语吟唱、《서로 사랑한단…》韩语），
说明平台**接受非中文人声**。但我们的目标听众是下沉中老年中文人群 →
**外语只宜做「点缀式吟唱」**（如国风里的梵语/和声吟唱段），**不做主体**。

**落到创作参数（叠加在 D 节之上，优先级更高）**：

- **副歌**：**6~10 行成块**，整块**原样重复 ≥2 次**，**第一句 = hook**。
- **单行**：**8~12 字**（写短、别写长句），韵脚优先 `人 / 你 / 着 / 了 / 雨 / 意` 这类顺口尾字。
- **篇幅**：参照 **~38 行**（不够 30 行的往往撑不起「整块重复两次」的结构）。
- **句式**：可用**自问自答式独白**（「你去哪」「你知不知道」）制造「这说的就是我」的代入感。
- **情绪词**：落在 **想 / 等 / 放下 / 痛** 这一组，避开 **恨 / 怨**（与 D 节「痛但克制」一致）。
- **纪律**：五层拆解**每轮都跑**（`fanqie_lyric.py`），新样本规律追加进本节，不覆盖旧结论。

#### 怎么打通的（纯静态逆向，不用手机 / 不用抓包 / 不用登录）

```
网页版 JS 包 → 后端主机名 api5-lite-sinfonlineb.novelfm.com（aid=8661 = FmMusic）
   → 下载官方 APK（com.xs.fm.lite）→ 解 dex 提字符串 → 真实路径前缀 /novelfm/...
   → tab_v2（金刚位）暴露 king_kong_type=music_rank + 榜单 Lynx 页 URL
   → 下载 music_rank_template.js → 里面写了完整 API 客户端（路径/参数/scene 枚举/字段名）
```

- **路径**：`POST /novelfm/bookmall/top/tabs/v1/`（`scene=13` = 榜单分类）
  + `POST /novelfm/bookmall/recommend/book/list/v1/`（`scene=119` = 榜单歌曲，`label_id` = 榜 ID）
- **裸接口**：**无需签名、无需登录、无需 Cookie**（同类小说接口对照组亦为裸接口）
- **必填**：`aid=8661`、`update_version_code=66732`（**漏了会报 `update_version_code is 0`**）
- **字段语义（易错）**：接口**不返回绝对名次** → **名次 = 列表顺序**；
  `stat_rank_desc` 是**名次涨跌**而非名次（`hidden`/`null`=新上榜、`>0` 升、`<0` 降、`0` 平）
- 工具：**`scripts/fanqie_rank.py`**（只读、纯 `requests`、零浏览器）；
  `fanqie_chart.py`（网页版）**降级为兜底**
