# 热歌研究档案（代创作前必读，持续迭代）

> **为什么要有这个文件**：凭感觉写歌 = 碰运气。
> 代创作前先研究当期热歌榜，把爆款的「创作思维模式」提炼出来再去写，命中率完全不同。
> **每次代创作前，先看本文件最后一期的研究，再做一次新搜索补充当期数据。**

## 研究方法（★ 2026-09-21 起，照做即可）

**现行标准流程（App 内部 + Tool 自动化，已全部固化）**：

1. **★ 跑 `fanqie_rank.py` 采番茄音乐 APP 官方榜**（**最准，且已打通**）：
   ```bat
   python fanqie_rank.py --rank 热歌榜              :: 单榜
   python fanqie_rank.py --rank 飙升榜,80后热歌,90后热歌
   python fanqie_rank.py --rank all --limit 50      :: 10 个榜全采（约 497 首）
   python fanqie_rank.py --list-ranks               :: 列出全部榜名
   ```
   拿到的是**用户在 APP「排行榜」里看到的同一份数据**：官方名次 + 涨跌幅 + 真实播放量
   + 收藏数 + **官方曲风标签**。子命令、字段语义、踩坑记录见 **G 节**。
2. **★ 跑 `fanqie_lyric.py` 拆「热歌榜前十首」歌词五层**（**研究本体在这里**）：
   ```bat
   python fanqie_lyric.py --top 10 --rank 热歌榜
   python fanqie_lyric.py --top 10 --rank 飙升榜    :: 想换样本源就换榜
   ```
   输出 `<workdir>/study/番茄歌词拆解-YYYY-MM-DD.md`（逐首全文 + 结构/记忆点/句式/韵脚/意象）。
3. **★★ 跑 `fanqie_recipe.py` 出「创作配方卡」**（**把研究压成能落笔的参数**）：
   ```bat
   python fanqie_recipe.py --ranks 热歌榜,80后热歌,90后热歌
   ```
   输出 `<workdir>/study/番茄创作配方-YYYY-MM-DD.md`——
   谁在听 / 题材主盘 / 歌名几个字 / 写几行 / 副歌几行 / 重复几次 / 韵脚挑哪几个 /
   **情绪需求四问模板** / 撞名清单 / 写完自检清单。见 **H 节**。
4. **★ 回答配方卡第七节的「听众情绪需求四问」**（写进本文件该轮的 D 节）。**四问不答完，不许开写。**
5. **交叉第三方榜看大盘风向**（抖音热歌榜 / 酷狗 / 短视频热歌榜）：搜索即可，
   **与第 1 步冲突时以番茄 APP 官方榜为准**。
6. **提炼而非抄歌名**：重点看**风格分布**和**爆款共性**，不是照抄某首歌。
7. **写回本文件**：新一期追加在最后，标注日期和来源，形成可对比的历史积累。

> ⚠️ **不要再用网页版数据当榜单**：番茄音乐**网页版没有榜单页**（18 个候选路径全回落首页），
> 只有首页「热门歌曲」推荐位，且**与 APP 榜单差距极大**
> （2026-09-21 实测：网页版 199 首与 APP 热歌榜 50 首**歌名交集 = 0 首**）。
> `fanqie_chart.py`（网页版）**已降级为兜底**，仅当 APP 接口不可用时才用。
>
> **历史口径提醒**：本文件 2026-08-30 ~ 2026-09-20 的期次用的是**第三方榜**
> （搜狐 / 酷狗 / 歌曲吧 / eemp3…），第十一轮 A/B 节用的是**网页版自排名次**。
> 这两类数据**口径都低于 G 节的 APP 官方榜**，**引用时不可与新榜数字混用**。

### C. 爆款共性（多篇文章口径一致，可信度高）

1. **旋律简洁抓耳**：主歌副歌区分明显，副歌记忆点强，**听一两遍就能跟着哼**。
2. **歌词共情、接地气**：写普通人的生活日常，或人人都经历过的情感，让人有代入感。
3. **副歌就是短视频 BGM**：多数二创只截取**副歌 15~30 秒**——
   所以**副歌必须在前 15 秒内就把情绪抛出来**，慢热的结构在短视频时代传播吃亏。
4. **老歌新唱是一条捷径**：经典旋律 + 新编曲（如弥渡山歌 PHONK 版）反差感强，自带认知度。
5. **国风的破圈公式**：传统民乐乐器（唢呐/古琴/二胡）开头抓耳 + 现代节拍 + 家国/古典意象歌词。

→ 共鸣抓手：**用「时间节点」而不是「抽象情绪」**
（例：那年 / 到现在 / 这一回 / 最后一次 / 又一年）。

（梦哑 / 舞女 / 赐我 / 来迟 —— 都是口语化短词，不是文艺长句）。

**五层拆解定义与本轮答案（口径已固化进脚本输出）**：

| 层 | 看什么 | 本轮样本的答案 |
|---|---|---|
| ① 结构 | 篇幅、行数、段落怎么切 | 平均 **38.3 行**，单行平均 **10.2 字** |
| ② 记忆点 | 重复最多的那句（hook）重复几次 | hook 平均重复 **4.0 次** |
| ③ 句式 | 口语 vs 文艺、有无对白/自问 | **自问自答式独白**（「你去哪」→「问你却张不出口来回答」） |
| ④ 韵脚 | 行尾字分布 | **人(15) 你(14) 着(13) 了(12) 遇(8) 意(8) 梦(6) 下(6) 上(6) 雨(6)** |
| ⑤ 意象/情绪 | 高频名词、高频动词 | 意象：**心(25) 花(15) 雨(14) 琴(14) 琵(14) 梦(13) 泪(13) 眼(10)**；情绪：**想(15) 等(8) 放下(7) 痛(7)** |

**★ 跨曲最硬的三条规律（可直接指导写词）**：

1. **10/10 首都有「整块重复副歌」** —— 副歌块平均 **7.9 行**，整块**原样重复 2.1 次**。
   即番茄爆款的副歌**不是「提炼 1~2 句副歌句」，而是「一整段原封不动再来一遍」**。
   → 写词时副歌要写成一个**能独立成段、且值得唱两遍的 6~10 行整体**，不要只押一两句。
   （极端例：《梦哑》副歌块 **10 行**、整块重复 2 次，占全曲 41 行的近一半。）
2. **hook 平均重复 4.0 次，且 hook 就落在副歌的第一/二句里**。
   样本原句：`爱一个人要学会放下`（梦哑）/ `弹一首琵琶曲 世人争相思意`（琵琶曲，两个版本共用）/
   `赐我一场相爱`（赐我）/ `你知不知道你就是我最爱的人`（最幸福的人）/ `有你别无所求了`。
   → **副歌第一句 = hook**，写的时候就要按「歌名级别的句子」去打磨，别把力道平均分给整段。
3. **韵脚几乎全是「人/你/着/了」这类最省力的口语尾字**，不是生僻雅字；且多组混押（-i / -u / -ng）。
   → **不要为押韵去挑生僻字。** 番茄听众要的是「顺口、听得清、像说话」，
   生僻字只会让 45~70 岁的听众第一次听就卡住。

**同时反证了两条第十轮（及更早）的错误假设**：

- ❌「国风要走文言/文艺长句」→ **错**。样本单行平均 **10.2 字**，最短的《梦哑》仅 **8.4 字**，
  全是**短句**；国风爆款《琵琶曲》走的是「器物 + 白话」（弹一首琵琶曲 / 世人争相思意），
  不是文言堆砌。**国风的「古」在配器和意象上，不在句法上。**
- ❌「副歌越短越好记」→ **半错**。短的是**单句**，长的是**整块** ——
  记忆靠**重复整块**（2.1 次），不是靠把句子砍短。**别为了「好记」把副歌写成两句孤零零的口号。**

**顺带一条形态发现**：TOP10 里有 **2 首外语 vocal**（《祈神怜》梵语吟唱、《서로 사랑한단…》韩语），
说明平台**接受非中文人声**。但我们的目标听众是下沉中老年中文人群 →
**外语只宜做「点缀式吟唱」**（如国风里的梵语/和声吟唱段），**不做主体**。

**落到创作参数（叠加在 D 节之上，优先级更高）**：

- **副歌**：**6~10 行成块**，整块**原样重复 ≥2 次**，**第一句 = hook**。
- **单行**：**8~12 字**（写短、别写长句），韵脚优先 `人 / 你 / 着 / 了 / 雨 / 意` 这类顺口尾字。
- **篇幅**：参照 **~38 行**（不够 30 行的往往撑不起「整块重复两次」的结构）。
- **句式**：可用**自问自答式独白**（「你去哪」「你知不知道」）制造「这说的就是我」的代入感。

### A. 第 4 步 —— 听众情绪需求四问（逐条作答；四问不答完不许开写）

**(1) 这期最热的几首，听众在它们身上要的是什么情绪？**

先看 TOP10 的**句式**（这是能直接搬的东西）：疑问句歌名占了 3/10 ——
《我是否也在你心中》《你有没有真的爱过我》《彻夜不归究竟为谁》。
**这三句都在问，而三首歌都不给答案。** 这不是巧合：听众要的**不是答案，是有人替他把这句话说出口**。
再看情绪落点：《甘心情愿》《最远的你是我最近的爱》《想你的时候问月亮》《天也不懂情》——
**四首全是「自持型」**（甘愿、最近的爱、问月亮、不懂情），没有一首是控诉型。
再看**年代结构**：配方卡的口径里 90年代(7) + 80年代(5) + 00年代(2) = **14 首（28%）是明确的老歌**，
TOP10 里《情网》《甘心情愿》《最远的你是我最近的爱》《天也不懂情》都是经典重制。
→ **结论：核心情绪 = 「我心里还装着你，可我已经不去追了」——单向的、悬置的、不要答案的爱。**
→ **附带结论（可落地）**：听众要**熟悉感**。旋律要能跟着唱，编曲不要贪新奇；
**「经典重制感」本身就是爆款要素**，不是偷懒。

**(2) 这个情绪是「宣泄」还是「出口」？**

**是出口。** 词频已经把这件事实证了：情绪动词 **`等`(26) / `想`(17)** 压倒性领先，
而 **`恨` 没进前列** —— 番茄听众的痛是**内耗型**（等、想），不是**外攻型**（恨、怨）。
场景也锁死了：**KTV必点歌(15) + 广场舞(13)** 是前二场景，
这两处都是**当众开唱**的地方 —— **唱不出口的歌词就等于不能上这两个场景**。
→ 副歌必须给一句**体面的自我交代**：「我记得，但我不怪谁 / 我不问了 / 我还在，可我不闹」。
**写「你凭什么」「你欠我的」直接出局。**

**(3) 听众的现实处境是什么？如何共鸣？**

80后(36%) + 70后(32%) = **68%**；主场景 KTV + 广场舞。
→ 五六线县城/乡镇、45~70 岁、子女在外、有旧情未了、有没走到最后的人。
→ **他们不缺能哭的歌，缺的是「被理解得体面」** —— 听完不能觉得自己可怜。
→ **必须用时间节点代替抽象情绪**：那一年 / 到现在 / 这么多年 / 一晃半辈子 / 又一年。
   （配方卡情绪词里 `那年`(3)、`岁月`(11)、`以后`(5)、`一生`(5) 全在，正是这个用法。）

**(4) 我这两首怎么让 TA 觉得「这说的就是我」？**

| 落点 | 做法 | 依据 |
|---|---|---|
| 歌名 | **4~8 字白话**，第一人称优先，收在 TA 自己会说的句子上 | 歌名 P25~P75 = 4~8 字；首字 `我`(10) > `你`(6) |
| 副歌第一句 | 按**歌名级句子**打磨，且整块 11 行原样重复 ≥2 次 | 副歌块中位 11 行；整块重复 100%(10/10) |
| 情绪动词 | 力气全花在 **「等」「想」** 上 | `等`(26)/`想`(17) vs `恨` 不进前列 |
| 意象 | 只用能看见的：**心 / 风 / 月 / 夜 / 门口 / 桌子** | 意象词 心(39)/风(36)/月(28) |
| 韵脚 | 挑**最省力的口语辙**一韵到底，禁生僻字 | 韵脚池全是口语尾字；听众第一遍听不清就划走 |

## 2026-09-23 第十三轮（第九批创作前 · 检验歌词与歌曲质量）

**本轮性质**：用户要求「检验一下歌词和歌曲质量是否过关」，并**首次要求出双语料词**。
所以本轮除了走完六步铁律，还额外做了一次**「单行字数」口径的实测校准**（见 D 节，结论推翻了我自己的初判）。

### A. 第 4 步 —— 听众情绪需求四问（逐条作答）

**(1) 这期最热的几首，听众在它们身上要的是什么情绪？**

- **情绪动词 `等`(24) 压倒一切** —— 远超 `想`(9)、`忘`(7)、`痛`(4)，而 `恨` 依然不在前列。
  听众的痛是**内耗型**（等、忘），不是**外攻型**（恨、怨）。
- **伤感 19/50（38%）+ 情歌 32/50（64%）**：伤害情歌是绝对主盘。
- **但最有信息量的是结构**：TOP10 里 7 首是「经典重制 + 版本后缀」——
  《情网（DJ版）》1057万、《甘心情愿（深情版）》1039万、《最远的你是我最近的爱》《天也不懂情》《潮湿的心》
  全是 80/90 年代老歌的重新编曲版。**听众要熟悉感，旋律得能跟着唱。**
- **「等」的三种写法**（可直接搬）：
  ① 反复追问型 ——《你有没有真的爱过我》首句**×2 在整首歌出现 3 次**（第1、26、30 行），且**每段 4 行一整块、重复 2 次**；
  ② 通感问天型 ——《我是否也在你心中》「我问问雨 我问问风」；
  ③ 碎片循环型 ——《潮湿的心》「谁能用爱烘干我 / 这颗潮湿的心」拆两行跨 4 行一句，重复 3 次。
→ **结论：核心情绪 = 「我还惦记着，但我不打算再回头了」。不是不要答案，是不问了。**

**(2) 这个情绪是「宣泄」还是「出口」？**

**是出口。** 两个主场景 —— **KTV必点歌(18) + 广场舞(17)** —— 都是**当众开唱**的地方，
唱不出口的歌词等于不能上这两个场景。
→ 但本轮发现**出口有两种，都得给**：
  - **体面的出口**（在「等」里保持尊严）：「我记得，但我不问了」
  - **态度的出口**（松一口气的痛快）：《山风等等我》562万（TOP5）、《院子的狗尾草》**▲56 名**（全榜涨幅第一）、
    《十个承诺九个哄》▲5 —— 共同点是**「把半生的将就换成自由」**这类**夺回自主权**的痛快。
→ **写「你凭什么」「你欠我的」直接出局；只写"我还在等"会漏掉半个盘子。**

**(3) 听众的现实处境是什么？如何共鸣？**

- 80后最爱(21/50=42%) + 70后最爱(19/50=38%) = **80%**；主场景 KTV + 广场舞。
- → 45~70 岁、上有老下有小、有旧情未了、有没说出口的委屈。
- → **必须用时间节点代替抽象情绪**：`岁月`(11) 是情绪词第 2 位。
- → **本轮新增洞察：这个人群最大的痛不是失恋，是「一辈子迁就别人」。**
  这是「将就换自由」这类歌能在榜上跑出来的原因，也是本轮第二首的落点。

**(4) 我这两首怎么让 TA 觉得「这说的就是我」？**

| 落点 | 做法 | 依据 |
|---|---|---|
| 歌名 | **4~9 字白话**，用**第一人称告知句**（不是疑问句） | 歌名 P25~P75=4~9 字；但本期疑问句已有 3 首在榜，避开 |
| 副歌第一句 | 按**歌名级句子**打磨，整块 ≥10 行**原样重复 ≥2 次**，hook 重复 ≥3 次 | 整块重复 100%(10/10) |
| 情绪动词 | 力气花在 **「等」「忘」「不将就」** 上 | `等`(24)/`忘`(7) vs `恨` 不前列 |
| 意象 | 只用能看见的：**风 / 老店 / 路口 / 酒 / 杯子 / 饭桌** | 意象词 心(38)/风(36)/月(22) |
| 韵脚 | 一韵到底的**口语辙**，禁生僻字 | 第一遍听不清就划走 |

### C. 第 6 步 —— 本轮落笔（双语料，各 2 个版本 = 4 作品）

**为什么是这 2 首**：配方卡把主盘算出来了，但**主盘 = 安全区也是同质化最重的地方**。
本轮做的不是「一个方向做两遍」，而是**把第(2)问的两种出口各写一首**：

| | 第一首《别打听我的消息》 | 第二首《半生的将就换自由》 |
|---|---|---|
| 取位 | **情绪极**（主盘正中：流行/情歌/伤感/轻柔） | **出口极**（榜上跑得最猛的那一支：态度的出口） |
| 对应四问 | 第(1)(4)问：把「等」写成**告知句** | 第(2)(3)问：**一辈子迁就别人**的痛点 |
| 歌名形态 | 主语省略的**祈使句**（TA 会说的白话） | 把**结果前置**的**白话陈述句**（把X换成Y） |
| 副歌结构 | **4 行一段 × 2 段 = 10 行块**，整块重复 2 次 | **10 行块**（含 2 行「不低头」碎句，学《潮湿的心》），重复 2 次 |
| hook 句 | 「别打听我的消息」全篇 **7 次** | 「把半生的将就」全篇 **9 次** |
| 韵脚 | **i 辙**（忆7/起4/以3/子2） | **ou 辙**（由9/头8/就5） |
| 行数 | 33 行 | 33 行 |
| 撞名 | **0 处**（对 518 榜上名 + 157 档案名 + 22 已发布曲库） | **0 处** |

**两首的关系**：第一首写「**我还在，但我不说了**」（体面）；
第二首写「**我迁就了半辈子，这回不迁就了**」（痛快）。
**一首给体面，一首给痛快** —— 正好是第(2)问要求的两条出口，互不打架。

### D. ★ 本轮最重要的方法论修正 —— 「单行字数」这个指标我一开始用错了

**发现的经过**：我按配方卡「单行 ≤10.6 字」自检，判我的副歌（14 字）**超标**，准备大改。
改之前先做了一件事：**把榜上样本的真实单行字数亲手量一遍**。结果：

| 量出来的事实 | 数字 |
|---|---|
| 10 首样本总行数 | **342 行** |
| 单行字数（含空格标点） | 均值 **9.44**、中位 **9**、P75 **11**、P90 **13**、**最大 16** |
| ≤10 字占比 | **68.7%** |
| 11~13 字占比 | 24.3% |
| **14~16 字占比** | **7.0%**（24 行） |
| ≥17 字 | **0 行** |

**而 14~16 字的行**，几乎全部是**副歌**，且形态**正是「两个分句用空格隔开」**：
- 《山风等等我》副歌：`山风山风等等我 带我去山那头`（**14 字**，重复 4 次）
- 《如果累了就回故乡》副歌：`如果累了就回故乡 去山野里走一趟`（**16 字**，重复 4 次）
- 《最远的你是我最近的爱》副歌：`人生风景在游走 每当孤独我回首`（**15 字**，重复 3 次）

→ **结论**：`10.6` 是**主歌**的达标线，**不是副歌的**。副歌写**双分句长句**恰恰是番茄爆款的标准形态
（对仗、好记、整块重复）。**我差一点因为用错尺子，把对齐榜首的副歌改坏。**

**教训（已同步 `LEARNED.md`）**：
> **自检清单里的每个数字，都要先确认它的统计口径和适用部位。**
> 配方卡给的是**全篇均值**（含大量短主歌行与纯语气行 —— 如《我是否也在你心中》均值只有 5.6，
> 因为它含「嗯嗯嗯」「啊」这类 1 字行），拿它去卡副歌，**指标会用反，把对的改成错的**。
> **根因不是「数字错」，是「我拿它当成了全篇统一线」。**

**配方卡该改的地方（本轮不动代码，留待下一轮）**：
- 第四节「单行字数」应拆成 **主歌 ≤11 字 / 副歌 13~16 字（双分句）**两条，而不是给一个全篇均值。
- 第十节自检清单同步拆开，否则每次都会误判副歌。
