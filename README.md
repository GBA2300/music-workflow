# music-workflow

**从「一句帮我写歌」到「番茄平台发布成功」的 AI 音乐自动化生产线。**

MiniMax 网页端生成音乐 → 自动下载 → 自动生成 1440×1440 封面 → 自动上传番茄音频创作平台
（填表 + 独家授权 + 跳转授权）→ 停在电子合同签署页，你本人签完即发布成功。

- **多账号通用**：不内置任何人的账号、手机号、Cookie。每个人用**自己的账号**跑自己的流程。
- **跨平台**：Windows / macOS / Linux 均可（浏览器清理逻辑已做跨平台处理）。
- **断点续传**：上传中途断网，恢复后自动接着传，不用从头再来。

---

## ⭐ 哪些步骤需要人参与？

这是最常被问的问题。整条流水线里**只有 4 个环节需要你动手**，其余全自动。

| # | 环节 | 谁做 | 频率 | 说明 |
|---|---|---|---|---|
| 1 | 安装依赖 | 🧑 人 | **一次性** | `pip install` + `playwright install chromium`，约 2 分钟 |
| 2 | 首次登录 MiniMax | 🧑 人 | **一次性** | 扫码 / 账号密码登录。**登录态存本地 `profile/`**，之后长期自动免登 |
| 3 | 首次登录番茄 | 🧑 人 | **一次性** | 同上，登录态存本地 `profile_fanqie/` |
| 4 | 写歌单和歌词 | 🧑 人 | 每批歌 | 这是创作部分，当然得你来（`tasks.csv` + `lyrics/*.txt`） |
| 5 | **签署电子合同** | 🧑 人 | **每批一次** | 需你本人收**短信验证码**完成签署。**签完 = 发布成功** |
| — | 生成音乐 / 下载 / 做封面 | 🤖 全自动 | — | 点生成、等转码、取名、存库、出封面 |
| — | 番茄填表（6 项） | 🤖 全自动 | — | 音频 / 歌词 / 歌名 / 词曲·制作人·歌手 / 封面 / AI 类型 |
| — | 第一步下一步、第二步授权签约 | 🤖 全自动 | — | 独家授权 + 签约身份「个人」+ 确认签署 + 跳转授权 |
| — | 防重复发布记录 | 🤖 全自动 | — | 签完自动写入 `published.json`，下次自动跳过 |

> **关于登录态**：Cookie 一般能维持数周到数月。过期后脚本会提示，重跑一次 `--login` 即可，
> 不需要重新配置任何东西。
>
> **关于第 5 步**：电子合同涉及法律责任，必须由本人收验证码签署，任何自动化都不应代劳。
> 脚本会一直把浏览器开着等你（最多 30 分钟），签完自动记录。

## 用 AI 助手调用时的协作方式

如果你是通过 AI 助手（WorkBuddy / Claude 等）使用本 skill，它会遵守三条纪律：

1. **先问歌词谁写** —— 不会默认代劳，也不会默认甩给你。会问清是「你自己写 / 它代写 / 混合分工」。
   若由它代写，会**先研究当期热歌榜**（`references/HOT_SONG_RESEARCH.md` 有按日期积累的研究档案），
   再结合番茄听众画像（60 后、70 后占比超 40%，主打下沉市场）来创作，
   而不是凭感觉写——每期研究都会追加回档案，越用越准。
2. **人工环节主动提醒** —— 登录、短信验证码、签合同这些环节会**提前预告 + 说清在哪个窗口点什么**，
   不会让脚本在后台空转而你完全不知情。
3. **搞不定就请你教它** —— 同一环节连续失败会立刻停下，给你**保姆级手动步骤**；
   你手动做一遍把过程回传（截图 / 每一步点了什么 / 页面文字），
   它学完写入 `references/LEARNED.md` 和 `config.json`，下次这里就自动处理了。

## 快速开始

### 1. 装依赖

```bash
pip install -r scripts/requirements.txt
playwright install chromium      # ⚠️ 这步别漏，否则浏览器起不来
```

> 无 Python？先装 [Python 3.9+](https://www.python.org/downloads/)（3.13 实测通过，只用标准库 + playwright/pillow）。
> Windows 用户若 `playwright` 命令找不到，用 `python -m playwright install chromium`。

### 2. 初始化你的工作目录

```bash
python scripts/init_workdir.py D:/my-music
cd D:/my-music
```

会生成一套**完全干净**的目录：脚本、配置、空的曲库 / 歌词目录、**空的登录态目录**。
每个人的工作目录互相独立，互不干扰。

### 3. 登录两个平台（各一次，之后全自动）

```bash
python generate.py --login        # 浏览器打开，用你的账号登录 MiniMax
python fanqie_upload.py --login   # 浏览器打开，用你的账号登录 番茄
```

登录成功、看到对应页面后脚本会自动退出，登录态保存在你的 `profile/` 和 `profile_fanqie/`。

> 若遇到「点了登录没反应 / 弹窗一闪就消失」，那是平台风控识别了自动化浏览器：
> ```bash
> python login_check.py minimax   # 或 fanqie，带反自动化检测 + 自动截图诊断
> ```

### 4. 写歌单和歌词

编辑 `tasks.csv`（照着里面的示例行格式写）：

```csv
歌名,风格描述,歌词文件,生成数量,纯音乐
我的第一首歌,治愈 流行 钢琴 72BPM 男声 温暖 希望,我的第一首歌.txt,2,否
```

歌词放到 `lyrics/我的第一首歌.txt`。

> 以 **`示例-`** 开头的行是格式示范，**不会真的生成**（专门做了跳过，避免你一跑就白烧额度）。

### 5. 生成音乐

```bash
python generate.py
```

自动：填歌名和风格 → 点生成 → 等出歌 → 下载 → 生成封面 → 存进 `library/`。
每首歌得到 `audio.mp3` + `cover.png` + `lyrics.txt` + `meta.json`。

### 6. 上传番茄

```bash
python fanqie_upload.py
```

自动：扫描 `library/` 里**还没发过**的歌 → 逐张填表 → 第一步下一步 → 独家授权 → 签约个人
→ 确认签署 → 等合同生成 → 点「跳转授权」→ **停下等你签合同**。

### 7. 签合同 = 发布成功 ★

浏览器会保持打开，你收验证码签完电子合同就算发布成功。
脚本检测到「签署成功 / 签署完成 / 签约成功 / 合同已生效」等字样后，自动把这首歌写进
`published.json`，**下次再跑就不会重复发**。

若自动检测没生效，手动补记：

```bash
python fanqie_upload.py --mark-published 我的第一首歌-01,我的第一首歌-02
```

## 常见问题

| 现象 | 解决 |
|---|---|
| 一直等「发布」按钮 | 番茄**没有发布按钮**，终点是签电子合同。脚本已停在合同页，签完即可 |
| 提示找不到生成按钮 | MiniMax 生成按钮文字是「限时免费」（底部紫色大按钮）。页面改版就改 `config.json` 的 selectors |
| 点了登录没反应 | 平台风控。用 `python login_check.py <平台>`，带反自动化检测；确认没别的 Chrome 占着同 profile |
| 上传中途断网 | 不用慌，脚本带断点续传，联网后重跑即可，已传好的会自动跳过 |
| 封面不合规 | 番茄要 PNG、≥1440×1440、≤10MB，脚本生成的就是 1440×1440，别手改后缀 |
| 想只发某几首 | `python fanqie_upload.py --songs 歌名-01,歌名-02` |
| 想重发已发过的 | 删掉 `published.json` 里对应记录 |

**页面改版选不到按钮时**，用自带的按钮探测器看真实按钮长什么样：

```bash
python inspect_buttons.py     # 列出页面所有可见按钮的文字/位置，照着改 config.json
```

## 隐私与安全

- ✅ 仓库里**不含任何人的账号、手机号、Cookie、登录态**。`profile/` 与 `profile_fanqie/`
  在工作目录里**初始为空**，由使用者自己登录生成。
- ✅ 脚本不含任何硬编码的个人数据，路径全部相对当前工作目录。
- ⚠️ **请勿把你的 `profile/`、`profile_fanqie/`、`published.json` 上传到任何公开仓库**——
  那等于把你的登录凭证交出去。仓库自带的 `.gitignore` 已帮你排除，直接提 issue/PR 是安全的。

## 目录结构

```
music-workflow/
├── README.md              本文件
├── SKILL.md               AI Agent 用的技能定义（配合 WorkBuddy / Claude 等）
├── references/
│   ├── USER_GUIDE.md      更详细的用户手册
│   ├── CREATION_GUIDE.md  番茄听众画像 + 代写歌词/风格的依据
│   └── LEARNED.md         踩坑经验沉淀（解决新问题后会回写这里）
└── scripts/
    ├── init_workdir.py    一键初始化工作目录（新人从这里开始）
    ├── generate.py        MiniMax 生成 + 下载 + 封面
    ├── cover.py           封面生成器
    ├── fanqie_upload.py   番茄上传填表 + 授权（终点：签合同）
    ├── login_check.py     登录诊断（专治「点登录没反应」）
    ├── probe_generate.py  生成探针（查「点生成后等不到歌」）
    ├── inspect_buttons.py 按钮探测器（页面改版时定位 selector）
    ├── browser_utils.py   跨平台浏览器清理
    ├── config.json        平台 URL、选择器、封面参数
    ├── tasks.csv          歌单模板
    └── requirements.txt   playwright, pillow
```
